# resume

Don Sumayan's resume, in three styles. Each page has a switcher to jump between them.

- `index.html`: classic one-page CV (main page)
- `starfield.html`: interactive starfield resume
- `manga.html`: manga-style resume
- `style-switch.css` / `style-switch.js`: glitch transition when switching styles
- `files/`: profile photo used by the classic CV

Static files only, no build step.
